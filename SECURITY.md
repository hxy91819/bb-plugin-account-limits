# Security

Please report security issues privately through the GitHub repository's security reporting feature, when available. Do not include tokens, account files, management keys, prompts or personal account details in public issues.

The plugin runs with BB plugin trust. Configure only a management service you control. Store keys in host environment variables or local key files. Do not commit local.json, environment files or credential exports. Upstream endpoint failures are displayed as errors or unknown usage, never as free capacity.
